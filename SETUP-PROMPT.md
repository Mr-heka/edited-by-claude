# Setup prompt

Copy the block below into a new **Claude Code** or **Codex** session and press Enter.

```text
https://github.com/Mr-heka/edited-by-claude

Install the Talking-Head Edit skill from this repository for me.

1. If the folder ~/edited-by-claude exists, update it with: git -C ~/edited-by-claude pull
   Otherwise download it with: git clone https://github.com/Mr-heka/edited-by-claude ~/edited-by-claude
2. Open ~/edited-by-claude/SETUP.md and follow it to the end. Run every command yourself.
```

It takes a few minutes. When it's done, start a new session and say **"Edit this video"** with the path to a talking-head clip.

To update later, paste the same block again.
